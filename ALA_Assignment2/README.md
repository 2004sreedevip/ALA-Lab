# ALA Assignment 2

## Semantic Tagging with GloVe and NumPy

This project implements semantic tagging using
pretrained GloVe word embeddings.

### Technologies Used

- Python
- NumPy
- Gensim
- GloVe Wiki Gigaword 50

### Project Features

1. Text preprocessing
2. Tag matrix construction
3. Text matrix construction
4. Cosine similarity using Vector class
5. Cosine similarity using NumPy
6. Numerical verification
7. Max pooling and tag ranking
8. Unit testing

### Execution

Install dependencies:

pip install -r requirements.txt

Run the project:

python -m src.main

Run unit tests:

python -m unittest discover -s tests -v
